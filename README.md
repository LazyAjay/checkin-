# CheckIn+ 🚀

**CheckIn+** is a workforce management application designed to help organizations track employee attendance, manage check-ins, and monitor location-based activity using geofencing.

---

## 📱 Features

- 📍 Location-based check-in with geofencing
- 👨‍💼 Admin and employee role management
- 📊 Employee activity tracking and reporting
- 📁 Bulk user import (Excel/CSV support)
- 🔔 Push notifications for alerts and updates
- 🛡️ Secure authentication system

---

## 🧠 How It Works

1. Admin creates projects and assigns locations
2. Employees log in and select their assigned project
3. Employees can check in only within allowed geofence locations
4. App verifies location and logs activity
5. Admin receives alerts if violations occur

---

## 🔐 Privacy & Security

- Data is transmitted securely using HTTPS
- Location data is used only for check-in validation
- Uploaded files (bulk import) are processed temporarily and not stored
- No data is sold or shared with third parties
